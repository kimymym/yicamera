# 📷 YI Action Camera Controller (Android)

> **최신 64비트 전용 안드로이드 기기를 위한 샤오미 YI 액션 카메라(1세대) 오픈소스 제어 앱**  
> **Package Name**: `com.github.kimymym.yicamera`

---

## 📌 1. 프로젝트 개요 및 목적

### 1.1 개발 배경
샤오미 YI 1세대 액션 카메라(Ambarella A7LS 칩셋)의 공식 앱(`sportscamera.apk`)은 **32비트 레거시 라이브러리에 종속**되어 있어, 최신 64비트 전용 스마트폰(Android 14+, Galaxy S24/S25, Pixel 7/8/9 등)에 설치 및 실행이 불가능합니다.

### 1.2 개발 목적
본 프로젝트는 레거시 독점 라이브러리 없이, **순수 최신 안드로이드 표준 기술**로 카메라의 무선 제어, 실시간 뷰파인더, 미디어 갤러리 및 다운로드, 카메라 시스템 설정을 100% 재구현한 애플리케이션입니다.

* **최신 64비트 OS 완벽 지원**: 최신 안드로이드 스마트폰에서도 제약 없이 쾌적하게 동작
* **가볍고 빠른 반응성**: 직관적이고 부드러운 사용자 경험 제공
* **안정적인 무선 통신**: 인터넷이 없는 액션캠 Wi-Fi 환경에서도 연결 끊김 없이 안정적으로 통신

## ✨ 2. 주요 기능 목록

> 💡 **상세 아키텍처, 네트워크 통신 구조 및 TCP 7878 JSON 프로토콜 명세는 [PRD 문서 (docs/prd_yiCameraApp.md)](docs/prd_yiCameraApp.md)에 상세히 기술되어 있습니다.**

### 1) 카메라 연결 (Connect)
* **카메라 Wi-Fi 자동 감지**: 카메라 Wi-Fi(`YD...`로 시작하는 AP) 연결 상태를 실시간 확인
* **원터치 Wi-Fi 설정 바로가기**: 미연결 시 버튼 터치 한 번으로 스마트폰 Wi-Fi 설정 화면 호출
* **자동 연결 및 제어 진입**: 카메라 연결이 감지되면 자동으로 세션을 맺고 메인 화면으로 즉시 진입

### 2) 실시간 라이브 뷰파인더 (Live Preview)
* **실시간 화면 프리뷰**: 카메라 렌즈가 비추는 화면을 스마트폰에서 실시간으로 확인
* **화면 상하 반전 (Flip 180°)**: 거치 방향에 맞춰 화면 상단 회전 버튼으로 프리뷰 및 카메라 녹화 방향을 즉시 180도 회전
* **3x4 구도 가이드 그리드**: 화면 상단 버튼으로 촬영 구도 보조선 On/Off 토글
* **촬영 모드 전환**: 대형 스위치 UI를 통해 사진 촬영 모드와 동영상 녹화 모드를 간편하게 전환
* **촬영 및 연속 클릭 방지**:
  * 사진 모드: 셔터 터치 시 촬영음/진동 피드백 제공
  * 동영상 모드: 녹화 시작 시 정지 버튼 전환 및 실시간 녹화 시간(`REC 00:23`) 표시
  * 명령 처리 중 셔터 연속 클릭 방지 및 안정화 쿨다운 적용
* **녹화 중 화면 켜짐 유지**: 긴 동영상 녹화 중에도 스마트폰 화면이 절전 모드로 꺼지지 않도록 유지
* **안전한 뒤로가기 제어**: 녹화 중에는 녹화 중지 확인 팝업, 대기 중에는 카메라 연결 해제 확인 팝업 표시

### 3) SD 카드 오류 감지 및 포맷 가이드
* 촬영 중 SD 카드 오류가 발생하면 사용자에게 **"SD 카드 포맷 안내 팝업"** 노출
* **[설정으로 이동]** 버튼 클릭 시 [설정] 탭의 [메모리 관리] 화면으로 즉시 이동하여 안전하게 포맷을 진행하도록 안내

### 4) 미디어 갤러리 및 다운로드 (Media Gallery)
* **초고속 썸네일 로딩**: 동영상 전용 내장 썸네일을 우선 로딩하여 버벅임 없는 쾌적한 갤러리 탐색 제공
* **간소화된 3열 그리드 뷰**:
  * 동영상: 우측 하단에 `[▶ 01:23]` 형태의 재생 시간 배지만 심플하게 표시
  * 사진: 불필요한 용량 문구를 숨기고 깔끔한 이미지 그리드 제공
* **선택 모드 및 일괄 다운로드**:
  * 상단 선택 모드 버튼 또는 길게 누르기(Long Press)로 다중 선택 진입
  * 원하는 파일들을 선택하여 하단 플로팅 버튼으로 일괄 스마트폰 다운로드
  * 다운로드 진행 중 파일별/전체 진행률(%) 팝업 표시
* **스마트폰 기본 갤러리 자동 저장**:
  * 다운로드 완료 즉시 스마트폰 기본 갤러리 앱(`Pictures/YiCamera`, `Movies/YiCamera`)에서 확인 가능
* **전체화면 미디어 뷰어**:
  * 사진: 고화질 원본 뷰어 및 핀치 줌 확대/축소 제스처 지원
  * 동영상: 스마트폰에서 즉시 스트리밍 재생 및 탐색바(Seekbar) 제어 (스마트폰 하단 바 침범 방지)

### 5) 카메라 시스템 및 Wi-Fi 설정 (Settings)
* **카메라 지원 옵션 자동 연동**: 연결된 카메라가 지원하는 실제 해상도와 옵션 목록을 실시간으로 가져와 메뉴 구성
* **촬영 설정**: 동영상 해상도 및 프레임(FPS), 사진 해상도, 렌즈 왜곡 보정, 영상 상하 반전(Flip)
* **카메라 기기 설정**: 비프음 볼륨, 알림음 종류, LED 인디케이터 모드, 자동 전원 끄기 시간
* **카메라 Wi-Fi 이름 및 비밀번호 변경**:
  * 카메라 Wi-Fi 이름(SSID) 및 비밀번호(8자 이상) 변경 기능 제공
  * 비밀번호 표시/숨기기(눈 아이콘) 토글 지원
* **메모리 관리 및 SD 카드 포맷**:
  * 사용 용량 및 잔여 용량 계산 및 시각적인 용량 게이지 바 제공
  * 카메라 자체 SD 카드 포맷 기능 제공

## 🚀 3. 설치 및 사용 방법

### 3.1 일반 사용자 사용 방법 (User Guide)

1. **카메라 전원 켜기**: 카메라 전면 전원 버튼을 눌러 전원을 켭니다.
2. **카메라 Wi-Fi 켜기**: 카메라 측면의 Wi-Fi 버튼을 누릅니다. 파란색 LED가 점멸하다가 켜지면 준비 완료입니다.
3. **스마트폰 Wi-Fi 연결**:
   * 스마트폰 Wi-Fi 설정에서 **`YD...`** (또는 `YDXJ_...`)로 시작하는 카메라 Wi-Fi를 선택합니다.
   * 기본 비밀번호: `1234567890` (초기 설정값)
   * *"인터넷에 연결되어 있지 않음"* 알림이 뜨더라도 **'연결 유지'**를 선택합니다.
4. **앱 실행 및 자동 제어**:
   * **YI Action Cam Controller** 앱을 실행합니다.
   * 카메라 연결이 감지되면 자동으로 메인 제어 화면으로 이동합니다.
5. **촬영 및 미디어 관리**:
   * 하단 탭을 통해 **[프리뷰]**, **[갤러리]**, **[설정]** 메뉴를 편리하게 이용할 수 있습니다.

### 3.2 개발자 빌드 및 설치 방법 (Developer Guide)

#### 사전 요구사항
* **JDK 17** 이상 (`JAVA_HOME` 환경 변수 설정 필요)
* **Android SDK** (API Level 35, Build Tools 35.0.0)
* **ADB (Android Debug Bridge)** 설치 및 스마트폰 USB 디버깅 활성화

#### A. 원터치 빌드 & 디바이스 설치 스크립트 실행 (권장)
Windows PowerShell에서 프로젝트 루트의 원터치 배포 스크립트를 실행합니다:

```powershell
powershell -ExecutionPolicy Bypass -File C:\devWorks\yicamera\build_and_install.ps1
```

> **스크립트 동작 과정**:
> 1. Gradle 8.11.1 Wrapper 환경 자동 구성
> 2. `assembleDebug` 클린 빌드 수행
> 3. 연결된 스마트폰에 최신 APK 설치 (`adb install -r`)
> 4. 메인 화면 자동 실행 (`com.github.kimymym.yicamera/.MainActivity`)

#### B. 수동 Gradle 빌드
```powershell
cd C:\devWorks\yicamera\yiCameraApp
./gradlew assembleDebug
```
* **빌드 결과물 위치**:
  * `C:\devWorks\yicamera\yiCameraApp\app\build\outputs\apk\debug\app-debug.apk`

#### C. 수동 ADB 설치 및 실행
```powershell
adb install -r C:\devWorks\yicamera\yiCameraApp\app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.github.kimymym.yicamera/.MainActivity
```
